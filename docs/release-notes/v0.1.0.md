The first public release of Lithify: Spotify Connect (librespot) for Lithe Audio Wi-Fi speakers,
installed next to the speaker's own software.

## Install

- **Windows:** download `Lithify-Windows.cmd` below and double-click it.
- **macOS:** in Terminal, `curl -fsSL https://raw.githubusercontent.com/TomaszKondraciuk/lithify/main/installer/install.sh | sh`
- **Linux:** in a terminal, `wget -qO- https://raw.githubusercontent.com/TomaszKondraciuk/lithify/main/installer/install.sh | sh`

The installer opens a wizard in your browser that finds the speaker and installs Lithify on it in
a few minutes. Spotify Premium is required. Details: [README](https://github.com/TomaszKondraciuk/lithify#readme).

## What it does

- A second Spotify Connect device on each speaker, running librespot from its development
  branch (with its latest fixes), built for the speaker's processor.
- The Spotify slider controls the speaker's own volume, shared with Google Cast and AirPlay.
- A web page on each speaker (`http://<speaker>:8090`, English and Polish): status, settings,
  connection tests, logs, one-button updates and rollback.
- A watchdog that restarts the built-in Spotify when it hangs, and gives the speaker to Cast,
  AirPlay or Bluetooth when they start playing.
- The firmware is not changed. `lithify uninstall` returns the speaker to its stock software.

## Tested

- Speaker: Lithe Audio Wi-Fi Ceiling Speaker V2, firmware p15525.144.0.
- Computers: Windows 11, macOS 15, Ubuntu 24.04.
- Not tested yet: WiFi PRO, Micro Subwoofer and the V2 stereo pair (same platform). Not supported:
  LS10 speakers (Wi-Fi Speaker V3, WiFi PRO 2, iO1). If you own one of these, please say so in
  Discussions.
